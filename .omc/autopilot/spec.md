# Autopilot spec — Шаг 2: карточка адресата (Hando)

Источник: артефакт «Hando — инвентарь и концепция», §20 «У адресата», §24 решения владельца; ответы владельца 10.09.

## Что должно быть
Уведомление адресату о поручении — карточка в личке с inline-кнопками. Один формат для задач из бота и из приложения.

Текст (человеческий, без ISO и URL):
```
📌 Вам поручено
«Подготовить отчёт»
От кого: Директор
Срок: пятница, 11 сентября, 15:00      (в поясе организации; нет срока — строки нет)
Важность: высокая                       (только если не средняя)
```
Кнопки (kind single/each/any): `✅ Принять` · `⏳ Не успею` / `✖ Отказать` · `📱 Открыть`.
Кнопки (kind ack): `👁 Ознакомился` · `📱 Открыть`.
`📱 Открыть` — inline web_app-кнопка на `https://hando.alrevion.com/?task=<id>` (App.tsx уже открывает задачу по `?task=`). Она добавляется ко ВСЕМ уведомлениям по задаче вместо строки с URL.

Поведение:
- Принять → строка адресата `accepted`; автору: «🚀 Принято в работу / «тема» / Кто: Азиз». Клавиатура адресата заменяется на одну кнопку Открыть.
- Ознакомился (ack) → `accepted` (rollup закрывает ack); автору «👁 Ознакомился».
- Не успею → бот спрашивает «Почему? Одной фразой» (BotState.await='late', task=id) → после текста: событие `late` с комментарием; автору: «⏳ Не успевает / «тема» / Кто: Азиз / Причина: …» + кнопки `Перенести на…` (открывает существующую клавиатуру срока due/cal — она author-gated) · `Оставить как есть` · `Переназначить` (только single/any).
- Отказать → спрашивает причину (await='decline') → `declined` (как POST /tasks/:id/decline); автору: «🚫 Отказ / «тема» / Кто / Причина» + кнопки `Переназначить` · `Отменить задачу`.
- Переназначить → список участников организации кнопками (`ra:<task>:<n>`, до 10, без автора) → выбранный получает карточку; все живые строки прежних адресатов → `declined` («переназначено»). ponytail: для each-рассылок кнопка не показывается.
- Отменить задачу → архив (`applyTransition to archived, action 'deleted'`), гейт — авторство.
- «Готово» из бота убирается: сдача только в приложении (решение владельца). Обработчик `done:` удаляется.
- Все кнопки: callback_data ≤ 64 байт; гейты: адресат — своя строка (`myAssignee`), автор — `task.author_id`.

## Не входит
Напоминания/сводка (шаг 3), иерархия (шаг 4), экраны приложения (шаг 5). «Не успею» в приложении — позже (app ⊇ bot, отметить в документе как долг).

## Приёмка
- Тесты (vitest workers, реальная D1): карточка с кнопками при создании из бота и из приложения; ack-вариант; accept → автор уведомлён, клавиатура заменена; late → вопрос → комментарий → автору кнопки; reassign → новая карточка, старые строки declined; decline → причина → автору кнопки; cancel → archived; чужая кнопка отвергается; `done:` больше не двигает строку.
- Инварианты: callback-data ≤ 64, реестры 2a/status-invariant не меняются (новых роутов нет), 352+ тестов зелёные, `tsc` чист, деплой.
