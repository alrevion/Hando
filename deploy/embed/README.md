# Эмбеддер рядом с Evi

Считает вектор фразы. Стоит на том же Oracle Ampere (`oracle-ampere`), где живёт
Evi, **отдельным** проектом compose: свои имена, свой том, свой порт. Контейнеры
`evi-core-1` и `evi-tts-1` он не трогает.

    ssh oracle-ampere
    cd ~/embed
    docker compose -p embed up -d          # поднять
    docker compose -p embed logs -f        # смотреть
    curl -s localhost:8088/health          # жив ли, загружена ли модель

Токен лежит в `~/embed/.env` на машине, в репозиторий не едет. Порт открыт
только на петле, наружу ходит туннель.

## Адрес снаружи

`https://handoai-api.alrevion.com` -- именной туннель Cloudflare «Hando AI»
(`292906ab-f3f1-46a1-a3aa-40cd28df0c79`), служба `hando-tunnel` на той же
машине. Токен туннеля -- `/etc/cloudflared/hando.env`, права 600 под root.

    systemctl status hando-tunnel          # наш туннель
    systemctl status cloudflared           # туннель Evi, его не трогаем

Имя ОДНОУРОВНЕВОЕ намеренно: бесплатный сертификат Cloudflare покрывает
`*.alrevion.com`, но не `*.handoai.alrevion.com`. Двухуровневое имя отвечало по
DNS и падало на проверке сертификата -- проверено. `handoai.alrevion.com`
оставлен свободным под сайт продукта.

Воркер знает адрес и токен как секреты `EMBED_URL` и `EMBED_TOKEN`
(`npx wrangler secret put ...`). Недоступен -- помощник просто отвечает моделью.

## Модель

Реестр fastembed 0.5.1 знает из многоязычных ровно три (проверено на машине):

| Модель | Измерений | Вес | На фразу (2 ядра) | Узбекский |
|---|---|---|---|---|
| paraphrase-multilingual-MiniLM-L12-v2 | 384 | 0.22 ГБ | 14 мс | нет |
| paraphrase-multilingual-mpnet-base-v2 | 768 | 1.0 ГБ | 35 мс | нет |
| intfloat/multilingual-e5-large | 1024 | 2.24 ГБ | втрое медленнее MiniLM | да |

`multilingual-e5-small` и `LaBSE` в реестре ОТСУТСТВУЮТ. Понадобится узбекский --
меняем `EMBED_MODEL` на `intfloat/multilingual-e5-large` и ждём загрузки 2.24 ГБ;
LaBSE потребует другого рантайма (sentence-transformers вместо fastembed).

## Что показал замер на живых фразах

Косинус между парами, MiniLM:

| Пара | Косинус |
|---|---|
| перефраз одной задачи | 0.76 … 0.95 |
| та же фраза, ДРУГОЕ ИМЯ | 0.79 … 0.85 |
| та же фраза, ДРУГОЙ СРОК | 0.95 |
| разные задачи | 0.40 … 0.56 |

Вывод, ради которого замер и делался: **порога, который отделит «тот же смысл» от
«те же слова, другой адресат», не существует**. Подмена срока даёт 0.95 -- выше,
чем настоящий перефраз. Поэтому кешировать разбор поручения целиком нельзя ни при
каком пороге: имя и срок надо вычёркивать ДО сравнения, а подставлять кодом.

Где вектор работает честно -- вопросы по руководству: «как отметить выполненную?»
против «где нажать что задача готова» дают 0.93, слотов там нет и путать нечего.
